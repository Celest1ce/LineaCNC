# Logos

## ✅ Logo SVG activé !

Un logo SVG placeholder est actuellement utilisé. **Remplacez-le par votre propre logo.**

## 📁 Fichiers :

```
logos/
├── logo.svg          # ✅ Logo principal (REMPLACEZ CE FICHIER)
├── logo-white.svg    # Logo blanc pour fond sombre (optionnel)
└── logo-icon.svg     # Icône seule (optionnel)
```

## 🎨 Comment remplacer le logo :

1. **Remplacez** le fichier `logo.svg` par votre propre logo
2. Le logo s'affichera automatiquement partout dans l'application
3. Aucune modification de code nécessaire !

## 📐 Format recommandé :

- **Format** : SVG (vectoriel)
- **Dimensions** : environ 200x50px pour le logo complet
- **Optimisation** : Utilisez https://jakearchibald.github.io/svgomg/ pour optimiser votre SVG
- **Couleurs** : Adaptez-les à votre palette bleue (ou laissez le composant gérer les couleurs)

## 📍 Où le logo est utilisé :

- ✅ **Navbar** (haut de toutes les pages)
- ✅ **Pages Login/Register** (centré en haut)
- ✅ **Footer** (bas de toutes les pages)

## 🎯 Variantes optionnelles :

Vous pouvez aussi créer :
- `logo-white.svg` - Version blanche pour fonds sombres
- `logo-icon.svg` - Version icône seule (pour favicon par exemple)
